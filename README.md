# Alumni Data Management System

A full-stack web application designed to help educational institutions manage alumni information, events, placements, job opportunities, and alumni engagement through a centralized platform.

## 📌 Project Overview

The Alumni Data Management System provides a secure platform for:

- Alumni registration and profile management
- Admin approval of alumni accounts
- Alumni directory
- Event management and registrations
- Job and placement opportunities
- Gallery (Photos & Videos)
- Announcements and notifications
- Alumni statistics dashboard
- Secure authentication and authorization
